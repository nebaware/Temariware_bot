Scope of the Project

In Scope
  • Next.js Mini App with 6 primary views
  • Telegram bot with 9 slash commands
  • PostgreSQL database with 7 entities
  • HMAC-based authentication layer
  • Screenshot-based payment verification
  • Mandatory document upload with compression
  • Per-job configurable application fees
  • Automatic job closure on hiring target
  • Channel broadcast to @TEMARIWARE
  • Per-subscriber push alerts
Out of Scope (v2)
  • Real Chapa / Telebirr API integration
  • Automated scraping of existing channels
  • In-app CV file storage (uses external links)
  • Email or SMS notifications
  • Employer dashboard with multi-job analytics
  • Saved/bookmarked jobs
  • Reporting beyond basic admin stats
Temariware — Senior Project Defense 7 / 27
  • In Scope items are all shipped and live in production.
  • Out of Scope items are deferred — each was a conscious cut to fit the 12-week timeline.
  • Chapa / Telebirr API requires business registration we did not have — deferred to v2.
  • Scraping was deferred to avoid legal ambiguity around existing channels.
  • Analytics and bookmarks were nice-to-haves that the advisor agreed to defer.
