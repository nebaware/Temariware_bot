Specific Objectives

Objectives 1 — 5
  1. Analyse limitations of existing informal Telegram job channels and elicit stakeholder requirements.
  2. Design a multi-section Mini App UI (job feed, detail, post, applications, profile, admin) with 3-language support.
  3. Design and implement a PostgreSQL database schema via Prisma ORM (users, jobs, applications, payments, subscriptions, verifications, settings).
  4. Implement a Telegram Bot webhook handling 9 slash commands and pushing instant alerts.
  5. Implement Telegram WebApp initData HMAC-SHA256 authentication.
Objectives 6 — 10
  1. Implement screenshot-based payment verification (job post fee + per-job application fee).
  2. Implement mandatory document upload (National ID, University ID, grade report) with image compression.
  3. Implement automatic job closure when positionsAvailable is reached.
  4. Deploy on free-tier infrastructure (Vercel + Neon Postgres + Telegram Bot API).
  5. Document the system per the Dire Dawa University industrial project guideline.
Temariware — Senior Project Defense 6 / 27
  • All ten objectives were completed — the system is live and accepting users.
  • Objectives 1, 2, and 4 were finished earliest; objective 6 (payment verification) took the most iteration.
