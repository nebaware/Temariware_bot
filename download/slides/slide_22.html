Component & Deployment

Components

  • Next.js Mini App (Vercel) — frontend + API routes
  • Telegram Bot Webhook (within Next.js) — receives updates
  • PostgreSQL Database (Neon Frankfurt) — data persistence
  • Telegram Bot API (external) — message sending + initData
  • @TEMARIWARE Channel (external) — public job broadcast

Deployment Nodes

  • Vercel Edge Network — runs Next.js globally
  • Neon Cloud (Frankfurt) — PostgreSQL, closest to Ethiopia
  • Telegram Cloud — Bot API + channel hosting
  • End users access via Telegram client (mobile/desktop/web)
  • Webhook: Telegram Cloud → Vercel via HTTPS
Full diagrams in Chapter 3, Figures 3.2 and 3.3.
- Bot webhook lives inside the same Next.js app to keep deployment single-artifact. - Frankfurt Neon region was the lowest-latency free-tier option for Ethiopian users. - Telegram Cloud handles all message delivery; we never run our own push infra. - Vercel Edge serves the Mini App globally, not just from one region. - Reference Figures 3.2 and 3.3 for the full component and deployment views.
