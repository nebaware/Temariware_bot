Sequence & Activity Diagrams

Sequence Diagrams

  • Apply to Job: Mini App → Jobs API → Applications API → Database → Employer (Telegram notification)
  • Accept Applicant and Pay: Employer → Accept API → Student (notification) → Pay API → Admin → Approve Payment API
  • Approve Job and Broadcast: Admin → Approve API → Channel (Telegram Bot API) → Subscribers (push)

Activity Diagrams

  • Job Posting & Approval Flow: submit → payment screenshot → admin review → approve/reject → broadcast → alerts
  • Application Lifecycle: PENDING → ACCEPTED → PAYMENT_PENDING → HIRED (or REJECTED/CLOSED)
  • Auto-close trigger: when filledPositions = positionsAvailable, mark job CLOSED, notify all parties
Full diagrams in Chapter 2, Figures 2.9–2.13.
- Apply-to-Job sequence spans four layers and ends with a Telegram push. - Application Lifecycle state transitions are enforced at the API layer. - Auto-close runs on every accept and idempotently marks the job CLOSED. - Approve-and-broadcast path was the trickiest because of channel URL-button limits. - Mention figures 2.9–2.13 for full notation if asked.
